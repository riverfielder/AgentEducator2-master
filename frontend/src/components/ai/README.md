# AI助手重构文档

## 概述
原始的 `AIAssistant.vue` 文件包含了超过2100行代码，功能复杂且耦合度高。本次重构将其拆分为多个小型、可复用的组件和组合式函数，提高了代码的可维护性和可测试性。

## 重构架构

### 组件层次结构

```
AIAssistant.vue (主容器)
├── ReferenceSelector.vue (引用选择器)
├── ChatHistory.vue (聊天历史侧边栏)
│   └── ChatHistoryItem.vue (单个聊天项)
├── StatusBar.vue (状态栏)
├── ChatMessages.vue (消息显示区域)
├── MessageInput.vue (消息输入区域)
│   └── SuggestionsDropdown.vue (@ 引用建议下拉框)
└── ChatDialogs.vue (各种对话框)
```

### 组合式函数 (Composables)

#### 1. `useChatManager.ts`
- **职责**: 管理聊天历史和会话
- **功能**: 
  - 加载聊天历史
  - 创建新对话
  - 选择对话
  - 编辑和删除对话标题
  - 时间格式化

#### 2. `useReferenceManager.ts`
- **职责**: 管理课程和视频引用
- **功能**:
  - 智能问答模式切换
  - 添加/移除引用
  - 清除所有引用

#### 3. `useSuggestions.ts`
- **职责**: 处理 @ 引用建议功能
- **功能**:
  - 搜索课程和视频
  - 显示建议下拉框
  - 键盘导航
  - 处理建议选择

#### 4. `useMessageSender.ts`
- **职责**: 处理消息发送和AI回复
- **功能**:
  - 发送消息到后端
  - 处理流式响应
  - 状态管理
  - 错误处理

#### 5. `useInputHandlers.ts`
- **职责**: 处理语音输入和图片上传
- **功能**:
  - 语音识别
  - 图片上传和预览
  - 文件处理

### 类型定义

#### `types/chat.ts`
定义了所有相关的TypeScript类型：
- `Chat`: 聊天会话
- `Message`: 单条消息
- `Source`: 引用来源
- `Reference`: 课程/视频引用
- `Suggestion`: 搜索建议
- `StatusData`: 状态数据
- `ContentFilterResult`: 内容过滤结果

## 重构带来的优势

### 1. 可维护性
- **单一职责**: 每个组件和函数只负责特定功能
- **清晰边界**: 明确的输入输出和接口定义
- **易于调试**: 问题定位更加精确

### 2. 可复用性
- **组件复用**: 子组件可以在其他页面复用
- **逻辑复用**: 组合式函数可以在不同组件中使用
- **类型复用**: 统一的类型定义确保一致性

### 3. 可测试性
- **单元测试**: 每个组合式函数都可以独立测试
- **组件测试**: 每个组件的行为都可以单独验证
- **集成测试**: 组件间的交互更容易测试

### 4. 性能优化
- **按需加载**: 可以实现组件的懒加载
- **状态隔离**: 避免不必要的重新渲染
- **内存管理**: 更好的资源清理

### 5. 团队协作
- **并行开发**: 不同开发者可以同时工作在不同组件上
- **代码审查**: 更小的文件便于代码审查
- **知识传递**: 新团队成员更容易理解和上手

## 使用指南

### 开发新功能
1. 如果是UI相关的新功能，考虑创建新的组件
2. 如果是逻辑相关的新功能，考虑创建新的组合式函数
3. 如果需要新的数据结构，在 `types/chat.ts` 中定义类型

### 修改现有功能
1. 定位到对应的组件或组合式函数
2. 修改时注意不要破坏现有的接口
3. 确保类型定义保持一致

### 添加测试
1. 为组合式函数编写单元测试
2. 为组件编写组件测试
3. 为整体流程编写集成测试

## 注意事项

1. **保持接口稳定**: 修改组件或函数的接口时要谨慎
2. **类型安全**: 充分利用TypeScript的类型检查
3. **错误处理**: 每个层级都应该有适当的错误处理
4. **性能考虑**: 避免不必要的响应式数据和计算
5. **文档更新**: 重大修改后及时更新文档

## 后续优化建议

1. **懒加载**: 实现组件的动态导入
2. **缓存策略**: 为聊天历史和建议搜索添加缓存
3. **虚拟滚动**: 为大量消息实现虚拟滚动
4. **国际化**: 支持多语言
5. **主题系统**: 支持深色模式等主题切换
